Demonstração institucional de alto padrão para a **Distribuidora Ponto Forte**, desenvolvida com estética comercial contemporânea, paleta baseada em grafite profundo (#0B0F17) e âmbar elétrico (#F59E0B), tipografia industrial marcante e total aderência às restrições legais e éticas do setor de distribuição de bebidas.

   - Hero com alternador interativo Antes / Depois da logomarca.
   - Apresentação institucional transparente e fiel aos dados conhecidos.
   - Seção de canais de atendimento com gerador interativo de mensagens formatadas para WhatsApp.

## 🚀 Como Executar o Projeto

### Opção 1: Abrir Diretamente no Navegador (Sem Instalação)
A compilação de produção foi gerada com caminhos relativos em `dist/index.html`. Você pode simplesmente dar um **duplo clique no arquivo `dist/index.html`** para visualizá-lo instantaneamente em qualquer navegador (Chrome, Edge, Firefox, Safari).

### Opção 2: Servidor de Desenvolvimento (Hot-Reload)
No terminal, dentro da pasta do projeto:
```bash
npm install
npm run dev
```
Acesse o link local exibido no terminal (geralmente `http://localhost:5173/`).

### Opção 3: Build de Produção
Para recompilar o projeto:
```bash
npm run build
```

### Opção 4: Linter & Qualidade
Para verificar a integridade do código:
```bash
npm run lint
```
*(Atualmente 0 erros e 0 avisos no linter).*
